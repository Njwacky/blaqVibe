⚙️ How Django handles this

Each card above is a Template row in Django DB. Admin pastes html_code + css_code. The gallery page loops {% for t in templates %} and filters by category.slug. The modal below is your template_detail.html with an <iframe src="/preview/slug/"> for isolation.

📋 The copy-paste magic

Click any card → see live preview + code tabs. The Copy button runs navigator.clipboard.writeText(code). That's all the frontend needs — Django just serves the strings. Add Prism.js for highlighting and you're done.
