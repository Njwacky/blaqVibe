# Stock App Vibes
AI Stock portfolio tracker — Django + React + Tailwind.

## What is this?
Tracks real-time stock prices, portfolio P&L, and sparkline charts. Built with Lovable in 2 hours, never published.

## Tech Stack
- Django 5, DRF
- React + Vite + Tailwind
- TwelveData API

## How to Run
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
# frontend
cd frontend && npm i && npm run dev
```
