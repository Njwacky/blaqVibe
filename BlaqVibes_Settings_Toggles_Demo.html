What Would Go Wrong

🔴 Turning off trading by accident
You toggle Allow trading Off → all your vibes become free → you lose stars income. Mitigation: Confirm dialog “Make all your vibes free? You’ll lose ★ income” + show “Free” badge before toggle.
🔴 Disabling Nolo + language — quality drops
Nolo Off → no review, language Off → no donut → buyers can’t judge → fewer trades. Mitigation: Default On, show “Recommended” badge, explain value.
🟡 Forks/PRs off breaks network
Allow forks Off → 10 existing forks stay, but new forks blocked → “Fork” button hidden, POST returns 403 fork page. Mitigation: Show “Forks disabled for your vibes” + keep existing forks.
🟡 Email off = missed trade
Email on trade Off → you don’t know someone traded → balance changes silently. Mitigation: In-app bell still shows (Trades page), email is extra.
🔒 ClamAV & R2 — Locked Always On (Critical)
Very critical — cannot be toggled. Virus scan and storage stay on. Attempt to toggle → 400 “Critical — always on”.
🟢 Rapid toggling
User spams toggle 10x/sec → 10 POSTs. Mitigation: Backend `toggle_setting` is idempotent, `update_fields=[key]`, no race, crush silently + 200.
🟢 JS disabled
Switch needs JS. Mitigation: Form fallback — page still works without JS, toggle via POST + reload (progressive enhancement).
