{% comment %}One line-glyph per public contact kind. The kind list lives in users/footer_contacts.py and each kind used to carry its own emoji in that table. That meant the platform decided how a contact rendered: one browser a paper plane, another a bird, none of them the site's own stroke weight — and the operator editor could not restyle it. Rendering the glyph from the kind here keeps the icon set ours and keeps the model layer free of presentation. Kinds are matched exhaustively; an unknown or future kind falls back to the link glyph rather than rendering nothing.{% endcomment %} {% if kind == 'email' %}{% elif kind == 'phone' %}{% elif kind == 'whatsapp' %}{% elif kind == 'website' %}{% else %}{% endif %}
