Before any upload

Three rules that prevent expensive mistakes

  1. 01
    Never upload secrets

    Store API keys and credentials in the destination’s secret settings, never in a ZIP, image, source bundle, or browser code.

  2. 02
    Test the shipped artifact

    A local editor run is not enough. Install or open the same build your users will receive through the host or store.

  3. 03
    Read the live policy before paying

    Fees, testing gates, supported countries, review rules, and platform requirements change. Every guide ends with primary sources.
