Try the platform itself. The link above is pre-filled with {{ demo_label }} ({{ demo_repo_url }}) — this site's own source. Importing it gives you a real 400-file project to read, remix and compare against, without writing a line first.
What gets left out, and why. Executables (.sh, .exe, .dll, …), node_modules/, .venv/, __pycache__/, .git/, symlinks, and anything shaped like a credential (.env, .npmrc, id_rsa, …) never enter a vibe. You are told exactly which paths were dropped — nothing is removed quietly. .env.example with empty values is fine and comes through.
Limits. 60 MB of archive, 1000 files, 200 MB uncompressed, 50 MB per file — the same ceilings the Publish page enforces. Over any of them, trim the repo or upload a ZIP by hand. Imported vibes are free (0 ★): the same bytes are one click away on GitHub.
Then what. The import lands as Pending Scan, exactly like every upload. It reaches the feed when the virus and vulnerability scans clear it, and it gets the same auto label and trust badge as anything else. Importing is not a shortcut past the checks.
