{% comment %} First-time welcome overlay — a full-screen modal shown once per account the first time a builder signs in, answering exactly three questions in 3+1 steps: 1 · What is BlaqVibes? 2 · What do I do here? 3 · Why should I care? then a closing CTA that hands over straight into the feed. State machine (users/welcome.py + users/welcome_views.py): · Profile.overlay_seen == True -> the include renders nothing and the boot script is not emitted (server truth; never again, any device). · False -> rendered and auto-opened by the inline boot script in base.html, UNLESS this browser's localStorage "blaq-welcome-seen" already answers (recovers a lost POST without re-nagging). data-force is reserved for tests/dev previews — no user path sets it. "screenshots" are pure-CSS miniatures (no image requests), so they render in light/dark theme and load with the page. The panel is marked up so the JS can drive Next/Previous/Close by class, dots by class, and steps hide/show by style — no inline handlers, which keeps the page's CSP happy. {% endcomment %}
