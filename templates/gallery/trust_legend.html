🛡️ The BlaqVibes Trust Badge
Most app galleries show you a card and hope for the best. BlaqVibes runs every upload through a scan pipeline — virus scan → secrets scan → dependency audit → publish — before it can reach your feed. The badge is the public verdict of that pipeline, and this page is exactly what each tier promises. Nothing on this page is decoration: every claim below is a check the code actually runs.

The three tiers
🛡️ {{ verified.label }}
Verified. {{ verified.title }}. The ZIP was virus-scanned clean, scanned for leaked API keys and passwords, and its dependency list was audited. Snippets (code pasted directly, no ZIP) earn the same badge — their code is secret-scanned and they have no installable dependencies.
🛡️ {{ scanned.label }}
Scanned. {{ scanned.title }} — for example the virus scanner was switched off by the operator, or the dependency audit could not run. We say what happened instead of rounding it up to a ✓. A vibe with possible secrets or a virus never gets this badge — it is held for human review or quarantined.
No badge
Unknown. No complete evidence — still pending, held for review, or published before the badge existed. Absence of the badge is the honest signal: we do not know, so we do not claim.
What we check — and what we honestly don't
🦠 Virus scanClamAV over the whole ZIP, before anything is published.
🔑 Secrets scanEvery file in the ZIP (and every snippet) is pattern-checked for leaked API keys, tokens and private keys. Filenames are stored for review — the secret values never leave the scan.
📦 Dependency auditnpm audit / pip-audit over the manifests, plus a registry check that named packages actually exist (AI-generated code sometimes invents package names — a trick attackers use to plant malware).
🧪 What we don't doWe do not execute your app. Previews run in a locked-down sandbox iframe, and anything our sandbox cannot run says "no live preview" plainly. The badge certifies what was scanned — it is not a guarantee the app does what its README says.
🧑‍⚖️ Reviews are humanStars and reviews are reputation from real people; the badge is machine evidence. They are different signals and we never mix them up.
How fakes are handled
Nobody can buy, vote, or style their way to a ✓. The tier is written by the scan pipeline alone — not by creators, not by stars, not by any form or API call.

Changing the content always resets the badge. Edit the ZIP, push over git, or merge a PR — the ✓ comes off instantly and only returns after the new bytes are re-scanned. A badge can never vouch for files nobody checked, so a buyer paying stars always gets exactly what was scanned.

A pending or quarantined vibe shows no badge at all. If the virus scanner is offline, the vibe simply does not auto-publish — missing evidence can never round itself up to "checked".

Found something we missed? Report it from any vibe's page — reports go to the human moderation queue, and a confirmed report pulls the vibe from the feed.
